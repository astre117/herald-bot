📋 CreateHaven Community Rules

1. No exchange of services (editing, cover work, ghostwriting favors, etc.) between members without an admin involved. If an admin isn't looped in, there's no escalation path if something goes wrong — so it's on you if it does.

2. Be respectful in the group — this is a space to grow together, not tear each other down.

3. Keep self-promotion to what's relevant to the cohort's goals — check with an admin before dropping unrelated links or offers.

4. Use /reportissue for Dravonis bugs or complaints instead of DMing an admin directly — it gets tracked and handled faster.

5. Sprints and 1:1 classes are opt-in — no pressure, but show up when you can, the community's better for it.
